# Roblox Studio Plugin

Local `.lua` plugin + `mango-studio-host` on `127.0.0.1:17880`.

- UI: DockWidget composer (Mango look).
- DataModel tools: `rbx_edit` only for existing scripts; confirm on delete/bulk prop.
- Install: `apps/roblox-studio/MangoStudio.cmd` (copies `MangoPlugin.lua`).
